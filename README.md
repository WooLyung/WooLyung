## Pinned Projects

### Lumencuit

Lightcuit을 개선 · 확장하여 다시 개발 중인 Unity 기반 3D 타일 퍼즐 게임입니다.

### Do The Rituals Yourselves

### Lightcuit

고등학교 교내 대회 출품용으로 개발한 게임으로, RG2R 엔진을 사용하여 개발한 빛 회로 퍼즐 게임입니다. 현재 개발 중인 Lumencuit의 초기 아이디어가 된 프로젝트입니다.

### RG2R

고등학교 동아리 엔진이었던 RG2 엔진을 바탕으로 재개발한 Direct2D 기반 게임 엔진입니다. 이후 동아리의 게임 엔진으로 활용되었습니다.
